# d20 Tabletop RPG Dice Roller Set
Full tabletop dice roller with expression parsing, critical hit effects, and roll history.
## Features
- Quick-roll buttons for d4, d6, d8, d10, d12, d20, d100
- Multi-dice expression input supporting formats like "3d6+2" or "2d8-1"
- Shows individual die results and total
- Golden glow critical hit animation on natural 20
- Roll history log for last 20 rolls
- Advantage/Disadvantage mode for d20
## Tech
Static SPA · Tailwind CDN · Canvas/localStorage
